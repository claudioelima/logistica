**1) Criar um repositório no GitHub (Web)**

1. Entre em <https://github.com> e faça login.
2. No canto superior direito, clique no **+** → **New repository**.
3. Preencha:
   - **Repository name** (nome do repositório)
   - **Description** (opcional)
   - **Public** (público) ou **Private** (privado)
4. Marque (recomendado):
   - ✅ **Add a README file** (já cria o README)
   - (opcional) **.gitignore** e **License**
5. Clique em **Create repository**.

**2) Adicionar colaboradores no repositório (Web)**

Para repo **privado**, você precisa permitir acesso; para **público**, também pode adicionar como colaborador.

1. Abra o repositório.
2. Clique em **Settings** (aba do repositório).
3. No menu da esquerda: **Collaborators** (às vezes fica em **Access** → **Collaborators**).
4. Clique em **Add people**.
5. Digite o **usuário** ou **e-mail** do GitHub da pessoa.
6. Selecione a pessoa → **Add**.
7. A pessoa precisa **aceitar o convite** (GitHub envia notificação/e-mail).

**3) Excluir um repositório (Web)**

⚠️ **Atenção:** apagar é **permanente** (a não ser que você tenha backup).

1. Abra o repositório.
2. Vá em **Settings**.
3. Role até o final em **Danger Zone**.
4. Clique em **Delete this repository**.
5. Confirme digitando owner/nome-do-repo (ex.: sergio123/meu-projeto).
6. Clique em **I understand… Delete**.

**4) Clonar um repositório**

**Opção A) Clonar pelo Git (PC) — mais comum**

1. No repositório, clique no botão verde **Code**.
2. Copie a URL (HTTPS).

**Opção B) Baixar sem Git (Web)**

1. **Code** → **Download ZIP**
2. Extrai no computador e pronto (mas não fica "linkado" ao Git).

**5) Criar um arquivo no repositório (Web)**

1. Abra o repositório.
2. Clique em **Add file** → **Create new file**.
3. No campo de nome, digite por exemplo:
   - index.html ou src/app.js
4. Escreva o conteúdo do arquivo.
5. Embaixo, em **Commit changes**:
   - mensagem (ex.: "Cria index.html")
6. Clique em **Commit changes**.

**6) Adicionar (upload) de um arquivo no repositório (Web)**

1. Abra o repositório.
2. Clique em **Add file** → **Upload files**.
3. Arraste o arquivo para a página (ou **choose your files**).
4. Escreva a mensagem do commit.
5. Clique em **Commit changes**.

**7) Criar uma pasta no repositório (Web)**

No GitHub, "pasta" existe quando tem **arquivo dentro**.

1. Abra o repositório.
2. **Add file** → **Create new file**.
3. No nome do arquivo, crie a pasta com /, exemplo:
   - aulas/README.md
   - imagens/.gitkeep (arquivo vazio só pra manter a pasta)
4. Escreva o conteúdo (ou deixe .gitkeep vazio).
5. **Commit changes**.

✅ Dica: usar .gitkeep é comum para "segurar" pastas vazias.

**8) Editar o README (Web)**

**Opção A) Editar pelo ícone do lápis**

1. Abra o repositório.
2. Clique no **README.md**.
3. Clique no ícone do **lápis (Edit this file)**.
4. Edite (Markdown).
5. **Commit changes**.

**Opção B) Editar direto na tela inicial (quando aparece o README)**

1. Na home do repo, role até o README.
2. Clique no ícone de edição (se aparecer).
3. Edite → commit.
